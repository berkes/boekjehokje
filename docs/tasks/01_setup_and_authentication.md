# Task: Setup and Authentication

## Overview

Initialize the project with React.js and TypeScript, set up Google OAuth for
user authentication, and implement localStorage for storing user preferences.

## Subtasks

### 1. Initialize the Project

- Create a new React.js project using TypeScript.
- Set up the project structure with the necessary directories and files.
- Install required dependencies (e.g., `react`, `react-dom`, `typescript`,
  `@types/react`, `@types/react-dom`).

### 2. Set Up Google OAuth

- Register the app with Google OAuth to obtain client credentials.
- Install the Google OAuth library (e.g., `react-google-login` or
  `@react-oauth/google`).
- Implement the OAuth flow to authenticate users.
- Store the user's authentication token securely.

### 3. Implement localStorage

- Create functions to save and retrieve user preferences from localStorage.
- Store user-specific data such as name, contact information, and preferences.
- Ensure data persistence across sessions.

## Expected Outcomes

- A fully initialized React.js project with TypeScript.
- Functional Google OAuth authentication.
- User preferences stored in localStorage.
